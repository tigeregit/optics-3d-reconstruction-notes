# 大纲（已确认 2026-10-26）

## 书名
《光学讲义：三维重建与结构光》
副标题：面向相机 / 投影 / 干涉 / 条纹实践者

## 读者与目标
- 非物理系硕士；应用统计背景；C++/CUDA 医学三维重建；做过图像分割训练；有数竞基础。
- 目标：按主流光学教程习惯补齐「够用」光学，每章落到三维重建里为什么要懂。

## 教学法
每章：效果 → 原理 → 限度 → 对象。对象段必须落到相机/投影/干涉/条纹/重建误差中的具体场景。

## 习题策略
- 每章 4–8 题：概念题 + 计算题 + 「重建场景」设计/诊断题。
- 答案与讲解放**章末**「习题讲解」（不另开总附录，便于单章自学）。
- 禁止只有背定义的题；至少一半题要能对应到相机/投影/条纹/点云误差。

## 预计篇幅
- 全书约 **110–140 页**（A4，含图与习题讲解）。
- 单章正文约 8–14 页；ch00、ch09 可略短；ch06、ch10 可略长。
