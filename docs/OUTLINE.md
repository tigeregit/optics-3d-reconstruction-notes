## 书名
《光学讲义：三维重建与结构光》
副标题：面向相机 / 投影 / 干涉 / 条纹实践者

## 读者与目标
- 非物理系硕士；应用统计背景；C++/CUDA 医学三维重建；做过图像分割训练；有数竞基础。
- 目标：按主流光学教程习惯补齐「够用」光学，每章落到三维重建里为什么要懂。

## 教学法
每章：效果 → 原理 → 限度 → 对象。对象段必须落到相机/投影/干涉/条纹/重建误差中的具体场景。
